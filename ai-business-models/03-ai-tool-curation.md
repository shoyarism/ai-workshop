## Setup Steps

### Step 1: Choose a Niche
- **Broad**: "Best AI tools for productivity"
- **Mid**: "Best AI tools for content creation"
- **Niche**: "Best AI tools for legal professionals" or "Best AI tools for indie hackers"

### Step 2: Set Up the Site
1. Create a free WordPress.com or Carrd site
2. Connect Google Search Console
3. Set up analytics
4. Install an SEO plugin (Yoast SEO for WordPress)

### Step 3: Build Content Pipeline
```python
1. TOOL DISCOVERY:
   - Scrape Product Hunt, AlternativeTo, G2 for new AI tools
   - Filter for tools with free tiers or free trials

2. REVIEW GENERATION:
   - LLM writes structured review templates
   - Include: overview, pricing, features, pros/cons, alternatives
   - Add personal testing notes where possible

3. ARTICLE PUBLISHING:
   - Auto-publish to WordPress via REST API
   - Include affiliate links naturally in context
   - Add comparison tables and "best for X" sections

4. PROMOTION:
   - Auto-share to relevant subreddits (where allowed)
   - Submit to AI tool directories
   - Engage in tool communities
```

### Step 4: Monetization Setup
1. Join affiliate programs: Amazon Associates, ShareASale, Impact, Rewardful
2. Sign up for software affiliate programs (most SaaS offer 30-50% recurring commissions)
3. Set up Media Kit for sponsored post inquiries

## Workflow & Best Practices

### Daily Workflow
| Time | Task | Automation Level |
|------|------|-----------------|
| Morning (15 min) | Research new AI tools, identify affiliate opportunities | Manual |
| Midday (automated) | Generate review drafts, publish to site | 100% automated |
| Afternoon (15 min) | Submit to directories, promote on social media | Manual |
| Evening (automated) | Track affiliate conversions, update top performers | 100% automated |

### Content Quality Standards
- **Review depth**: 1,000+ words per tool review
- **Originality**: Test tools personally where possible
- **Update policy**: Update reviews quarterly as tools change
- **Disclosure**: Clear affiliate disclosure on every page

### SEO Best Practices
- Target "best [X] tool" queries with low-to-medium competition
- Create comparison tables (schema markup for rich snippets)
- Build internal linking: tool reviews → category pages
- Target featured snippets with concise "best for X" sections

### Warning Signs
- ** FTC disclosure**: Must clearly state affiliate relationships
- ** Google penalty**: Avoid thin content, auto-generated spam
- ** Affiliate commission changes**: Monitor program terms monthly
