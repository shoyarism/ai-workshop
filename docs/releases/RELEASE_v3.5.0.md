## 📦 Getting Started

```bash
# Clone and install
git clone https://github.com/shoyarism/ai-workshop.git
cd ai-workshop

# Option A: uv (fastest)
uv sync

# Option B: pip
pip install -e .

# Arm the Git Bailiff pre-commit gate
workshop court bailiff install

# Run strict system diagnostics
workshop doctor --strict
```
