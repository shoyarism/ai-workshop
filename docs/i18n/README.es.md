## 01 // INICIO RÁPIDO (EN 60 SEGUNDOS)

### Opción A: Configuración Local (Recomendada)

Elija `uv` (más rápido) o `pip` estándar:

```bash
# 1. Clonar el repositorio
git clone https://github.com/shoyarism/ai-workshop.git
cd ai-workshop

# 2. Instalar dependencias (elija UNA)
uv sync                 # Con uv
pip install -e .        # Con pip tradicional

# 3. Armar los interceptores pre-commit (Git Bailiff)
workshop court bailiff install

# 4. Ejecutar diagnóstico de salud del sistema
workshop doctor --strict
pytest tests
```

### Opción B: Protocolo en la Nube Zero-Clone

Transmita cualquier manual de ejecución directamente al contexto de su agente usando `curl`:

```bash
curl -fsSL https://raw.githubusercontent.com/shoyarism/ai-workshop/main/skills/dev-house/using-superpowers/SKILL.md
```
