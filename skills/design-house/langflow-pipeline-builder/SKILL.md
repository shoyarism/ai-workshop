# Langflow Multi-Agent Orchestration Engine

Langflow provides a modular graph architecture for composing LLMs, vector stores, prompt templates, tools, and agent loops visually or programmatically in Python.

## Core Capabilities
- **Visual Flow Design**: Canvas interface for multi-agent loops and tool attachments.
- **Python Code Export**: Export visual flows to standalone executable Python scripts.
- **Custom Tool Integration**: Connect any Workshop MCP server or Python function into a flow.
