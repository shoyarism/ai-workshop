# Tailark

Tailark provides production-ready marketing blocks and page layouts built on top of Tailwind CSS and Shadcn UI.

## Components & Blocks
- **Hero Sections:** Animated headings, split layouts, video modals.
- **Feature Sections:** Interactive tabs, grid cards, dark-mode blocks.
- **Pricing & FAQ:** Tiered billing cards, expandable accordions.

## Best Practices
- **Shadcn Registry:** Add blocks via Shadcn CLI / registry inputs where supported.
- **Semantic Tokens:** Maintain standard CSS variable themes (`bg-background`, `text-primary`) across all marketing blocks.
