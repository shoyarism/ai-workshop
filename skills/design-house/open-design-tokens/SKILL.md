# OpenDesign System & UI Component Suite

OpenDesign provides a unified design token architecture, modern UI component specifications, color palette systems, and typography scales designed for automated agent frontend construction.

## Core Principles
- **Token Consistency**: Strict semantic color tokens (--primary, --surface, --accent).
- **Accessible Contrast**: WCAG AAA compliant default pairings.
- **Component Contracts**: Type-safe React/Tailwind component definitions.
