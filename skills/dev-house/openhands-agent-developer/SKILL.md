# OpenHands Autonomous Software Engineering Platform

OpenHands (formerly OpenDevin) is a full-stack platform for autonomous AI software development agents that plan, write code, run terminals, execute tests, and iterate autonomously.

## Core Architecture
- **Agent Runtime**: Event-driven architecture with Sandboxed Docker execution.
- **Tools**: Bash execution, file editing, web browser navigation, and lint verification.
- **Benchmark Proven**: High SWE-bench solve rates for end-to-end repository problem solving.
