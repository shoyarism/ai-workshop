# React Bits

React Bits offers copy-paste animated components, micro-interactions, text effects, and background animations designed for React, Tailwind CSS, and Framer Motion applications.

## Key Categories
- **Text Animations:** Split text, shiny text, blur text, wave text.
- **Components:** Infinite menu, dock navigation, magnetic buttons, tilt cards.
- **Backgrounds:** Grid distortion, wave background, aurora background.

## Best Practices
- **Avoid AI regeneration:** Copy exact animation logic from React Bits instead of prompting AI to build complex canvas/CSS keyframe animations from scratch.
- **Tailwind Integration:** Ensure `framer-motion` and `clsx` / `tailwind-merge` are configured before pasting components.
