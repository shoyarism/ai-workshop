# Stagehand AI Web Automation Engine

Stagehand combines Playwright with AI models to perform complex web interactions (act, observe, extract) using high-level natural language instructions without fragile CSS selectors.

## Core Actions
- **page.act()**: Perform natural actions ('Click the blue Sign In button and enter credentials').
- **page.extract()**: Extract structured data with Pydantic/Zod schemas.
- **page.observe()**: Discover available interactive elements and actions on the page.
