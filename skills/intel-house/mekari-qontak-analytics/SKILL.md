# Mekari Qontak CRM & Omnichannel Analytics Skill

## Overview
Standardized data schema, metrics processing, and analysis pipeline for **Mekari Qontak Omnichannel & CRM** in healthcare and hospital environments. Provides structured models for customer care agent SLA tracking, WhatsApp Business API broadcast metrics, incoming ticket categories, and CSAT (Customer Satisfaction Score) evaluation.

## Key Metrics & Dimensions
1. **Inbound Channel Breakdown**: WhatsApp Official API, Instagram DM, Facebook Messenger, Web Live Chat.
2. **Agent SLA & Throughput**: First Response Time (FRT), Resolution Time (RT), CSAT Score, Ticket Handled per Agent.
3. **Hospital Inquiry Categorization**: Jadwal Dokter, Tarif & Fasilitas, BPJS / Asuransi, Booking Poli, Handling Complaint.
4. **Broadcast & Saluran Campaign Conversion**: Broadcast open rate, link click-through to booking conversion.
