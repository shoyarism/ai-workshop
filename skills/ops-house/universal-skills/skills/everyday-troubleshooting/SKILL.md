# Everyday Troubleshooting

1. Ask the exact model, version and what happened (if not given).
2. Start with the simple checks: restart, cables, updates, settings, storage.
3. Give steps in order, one at a time, with how to confirm each worked.
4. Search for the official guide for that exact model or version.
5. Warn before anything that can lose data. Back up first.
6. If it is still broken, say when to contact support or a technician.
