# Context Management

- Summarize long tool output to the few facts you need. Do not paste whole files into your reasoning.
- Read files in parts. Search inside them instead of loading everything.
- Load only the skills the current task needs.
- On long tasks, write a short progress note every few steps: goal, done, next, open issues.
- Save durable facts (preferences, decisions) to memory. Do not save temporary details.
- One task per session where possible. Start fresh when the topic changes.
