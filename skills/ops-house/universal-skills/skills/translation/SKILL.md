# Translation

1. Confirm source and target language, and the register (formal or casual) if it is unclear.
2. Translate meaning and tone, not word by word. Keep names, numbers and formatting.
3. Use natural phrasing a native speaker would use. Avoid literal idioms.
4. Keep terms consistent across the text.
5. Flag ambiguous phrases and give the alternative reading in one line.
6. For non-Latin scripts, give a romanization only if asked.
