# Git And Project Hygiene

- Commit small, with messages that say what and why.
- Never commit secrets, keys, .env files or large binaries. Add them to .gitignore.
- Keep a README: what it is, how to install, how to run.
- Name folders and files consistently. Keep one place for each kind of thing.
- Before risky changes: commit or copy a backup. After: test.
- For backups, keep copies in at least two places.
