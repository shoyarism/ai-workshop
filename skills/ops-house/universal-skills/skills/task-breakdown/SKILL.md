# Task Breakdown

1. Write the end result in one sentence.
2. List the pieces needed. Each piece must have a visible output.
3. Order by dependency. Put the riskiest or most uncertain piece early.
4. Add a checkpoint after each piece: how will you know it is right?
5. Estimate effort roughly (small, medium, large). Flag anything large and split it again.
6. Do one piece at a time. Report progress briefly.
