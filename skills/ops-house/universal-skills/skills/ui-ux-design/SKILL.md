# Ui Ux Design

1. Define the user's goal and the one main action per screen.
2. Sketch the flow before the screens: start, steps, end, error.
3. Design every state: empty, loading, error, success.
4. Mobile first. Tap targets at least 44 px. Clear labels, not icons alone.
5. Accessibility: contrast, focus states, text that can resize, alt text.
6. Consistency: reuse the same buttons, spacing and wording.
7. Cut features and options until the main task is obvious.
