# Brand Identity

Process:
1. Understand: what it is, who it is for, 3 feeling words, 2 to 3 reference brands to avoid copying.
2. Name: see naming-and-trademark-screening.
3. Idea: one sentence. The mark, name and story must all point at it.
4. Mark: simple geometric form, works in one colour and small.
5. Palette: base, text, one accent used sparingly, plus 1 to 2 supports.
6. Type: one display face for headlines, one text face, one mono if technical.
7. Voice: 3 traits with example lines.
8. Applications: card, social post, interface sample.
9. Deliver as one clean HTML brand board when asked for a visual.
Do not copy a reference. Take principles from it, not shapes.
