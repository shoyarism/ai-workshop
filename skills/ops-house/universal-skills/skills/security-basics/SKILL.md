# Security Basics

- Keep keys in environment variables or a secrets file outside version control.
- Never print, log or paste full keys. Rotate a key if it leaks.
- Use unique passwords and two-factor authentication.
- Keep self-hosted tools off the public internet unless protected. Prefer localhost.
- Update software. Back up before big changes.
- Do not run unknown scripts without reading them.
