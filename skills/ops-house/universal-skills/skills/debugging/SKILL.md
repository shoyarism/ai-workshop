# Debugging

1. Reproduce the problem. Get the exact error and the steps.
2. Read the error from the bottom: what failed, where.
3. Form one hypothesis. Test it with the smallest change or a print/log.
4. Change one thing at a time. Re-run after each change.
5. Check the usual suspects: typos, wrong path, wrong version, missing dependency, bad input, permissions.
6. If stuck after 3 attempts, simplify to a minimal example or try a different approach.
7. Explain the root cause in one sentence and what fixed it.
