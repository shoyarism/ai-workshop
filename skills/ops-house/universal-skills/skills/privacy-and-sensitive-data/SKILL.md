# Privacy And Sensitive Data

- Treat names, IDs, health, financial, client and employer data as sensitive.
- Free-tier model providers may log or use prompts. Do not send sensitive data through them. Remove or replace names and numbers first.
- Share only what the task needs.
- Never store passwords, card numbers, ID numbers or API keys in memory or notes.
- If a task needs sensitive data, tell the user and suggest a private or local option.
