# Think Before Acting

1. Restate the goal in one sentence.
2. List what you know and what is missing.
3. If a missing detail blocks the work, ask ONE short question. Otherwise write your assumption in one line and continue.
4. Make a plan of 3 to 7 steps. Each step should produce something checkable.
5. Do the steps in order. After each, confirm it worked.

Avoid: starting to build before the goal is clear; asking several questions at once; over-planning simple tasks (a one-step task needs no plan).
