# Social Media Posts

- One message per post. Hook in the first line.
- Match the platform: Instagram (visual-first, short caption, a few hashtags), LinkedIn (professional, insight-led), X (very short).
- Write in the brand's voice. Avoid hype and spammy hashtag walls.
- End with a simple call to action if there is one.
- Offer 2 to 3 variants only if asked. Never invent stats or quotes.
