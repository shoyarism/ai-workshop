# Color And Type

Colour:
- Pick 1 base, 1 text, 1 accent. Add supports only if needed. Use the accent once per layout.
- Check contrast: body text needs about 4.5:1 against its background.
- Do not rely on colour alone to carry meaning.
Type:
- Maximum two typefaces. Create hierarchy with size and weight.
- Body 16 to 18 px for screens, line height 1.4 to 1.6, line length 45 to 75 characters.
- Tight tracking on big headings, open tracking on small caps labels.
- Always give a fallback font stack.
