# Editing And Proofreading

1. Keep the author's meaning and voice. Change only what needs changing.
2. First pass: errors (spelling, grammar, punctuation, wrong words).
3. Second pass: clarity (long sentences, vague words, order of ideas).
4. Do not rewrite style unless asked. If a flagged-only mode is requested, list issues without changing the text.
5. Return the corrected text. Add a short list of the main changes only if useful.
6. Never add new facts.
