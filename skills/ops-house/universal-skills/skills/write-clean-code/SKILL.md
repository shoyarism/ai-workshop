# Write Clean Code

1. Confirm the goal, inputs, outputs and the environment (OS, language version).
2. Write the simplest thing that works. Clear names, small functions, no dead code.
3. Handle errors and empty input. No silent failures.
4. Never hard-code secrets. Use environment variables or a config file.
5. Add short comments for why, not what.
6. Run it. Test normal, empty and bad input. Fix before sharing.
7. Over about 10 lines: save to a file and give the path and how to run it.
