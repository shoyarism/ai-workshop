# Design Critique

1. Start with the goal: does the design do its job for its audience?
2. Check in order: message clarity, hierarchy, layout, colour and contrast, type, consistency, details.
3. Give specific, kind, actionable notes ("increase title size and cut the second line"), not "make it pop".
4. Name what works, then the top 3 fixes by impact.
5. Separate opinion from rule (contrast failure is a rule; preference is an opinion).
