# Web Html Css

- One self-contained HTML file unless told otherwise. Semantic tags, responsive layout (flexbox or grid), relative units.
- Include the viewport meta tag. Mobile first. Test narrow widths.
- Define colours and fonts as CSS variables. Provide font fallbacks.
- Images: inline or data URIs when self-contained; add alt text.
- Do not use external scripts unless needed. Pin versions.
- Accessible: contrast, focus styles, labels for inputs.
- Open the page and check it before delivering.
