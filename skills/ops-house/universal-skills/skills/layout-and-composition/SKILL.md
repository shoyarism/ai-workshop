# Layout And Composition

1. One focal point. Everything else supports it.
2. Use a grid. Align to it. Repeat spacing values (e.g. 8, 16, 24, 48).
3. Whitespace is a feature. When it feels crowded, remove an element before shrinking.
4. Group related things close together. Separate unrelated groups.
5. Order the reading path: headline, visual, detail, action.
6. Check on a small screen and at a distance (squint test).
