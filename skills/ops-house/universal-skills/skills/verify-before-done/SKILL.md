# Verify Before Done

Before you say "done":
1. Re-read the original request. List every requirement.
2. Tick each one against the real output, not your memory of it.
3. Run, open, render or test the output. Files: confirm they exist at the stated path and open.
4. Check names, numbers, dates, links and spelling.
5. If something could not be verified, say exactly what and why.

In the final message, state what you checked in one line. Never claim a check you did not do.
