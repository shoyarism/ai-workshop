# Data Analysis Spreadsheets

1. Look at the data first: columns, types, missing values, duplicates, obvious errors.
2. Clean in a copy. Record what you changed.
3. Define the question before computing.
4. Use formulas or scripts, not mental arithmetic. Check totals two ways.
5. Charts: right type (line for time, bar for categories), clear title, labelled axes, units, no clutter.
6. Report the answer first, then method, then caveats (sample size, missing data).
7. Do not invent data. Mark assumptions.
