# Logo And Marks

- Start with the idea, not decoration. One concept per mark.
- Use simple shapes. It must read at 16px and in one colour on light and dark.
- Check: is it distinct from known marks? Is it balanced? Does it look right rotated 5 degrees (no accidental shapes)?
- Provide: primary lockup, stacked, mark only, light and dark versions.
- Clear space around the mark equals a fixed unit from the mark.
- Avoid: gradients as a requirement, tiny details, clipart, copying a reference or a known brand.
- State that AI-drawn vector marks are concepts; final artwork should be refined in a design tool.
