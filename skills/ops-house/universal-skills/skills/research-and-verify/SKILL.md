# Research And Verify

1. Search first. Do not answer from memory for anything time-sensitive.
2. Use short, specific queries (1 to 6 words). Put exact names in quotes. Vary the wording if the first query misses.
3. For important claims use at least two independent sources. Prefer official sites, documentation and primary sources over blogs and aggregators.
4. Note the date of each source. Prefer recent sources for fast-changing topics.
5. If sources disagree, say so and explain which you trust more.
6. Paraphrase. Never copy long passages. Never invent a URL or a quote.
7. No results does not prove something does not exist. Say "I found no evidence of X", not "X does not exist".
8. Say what you could not find.
