# Project Planning

1. Goal, deliverables, deadline, constraints, who does what.
2. Break into tasks (see task-breakdown). Estimate each.
3. Order by dependency. Mark the critical path.
4. Add milestones and a buffer (about 20 percent).
5. List risks and one mitigation each.
6. Output: a short table (task, owner, due, status). Update it as work progresses.
