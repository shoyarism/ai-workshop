# 🎯 Career Ops: Autonomous Career & Job Search Command Center

> **Purpose:** Applies the same rigorous agentic engineering workflows to job hunting: parsing complex job descriptions, matching skills against a user master profile, generating tailored application materials, and tracking status.

---

## 1. Core Workflow Capabilities

1. **Job Description Deconstruction:**
   - Ingest raw job listing text or URLs.
   - Extract hard technical requirements, preferred qualifications, tech stack, and company culture signals.
2. **Match Score Matrix:**
   - Compare the candidate's master experience profile against job requirements.
   - Output an objective compatibility score (0–100%) and identify skill gaps or talking points.
3. **Tailored Resume & Cover Letter Generation:**
   - Reframe authentic achievements using strong action verbs and quantified impact metrics (`X resulted in Y% improvement`).
   - Format into clean, parseable Markdown or LaTeX templates matching ATS standards.
4. **Local Pipeline Tracking:**
   - Maintain a local Markdown/JSON application pipeline tracker (`Company`, `Role`, `Applied Date`, `Status`, `Follow-up Date`).
