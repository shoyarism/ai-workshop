# 🗺️ Workshop OS — Technical Roadmap

This roadmap outlines the planned evolution of Workshop OS from an agent harness into a universal standard for quality-gated autonomous software engineering.

---

## Phase 1: Core Hardening & Anti-Slop (v3.5 — Current)
- [x] **Slop Court Quality Gate**: 38 codified statutes (FEL-01..08, MIS-01..06) with 3-juror tribunal.
- [x] **Git Bailiff**: Pre-commit and pre-push automated interception.
- [x] **7 Sovereign Houses**: 2,147 verified runbooks categorized into modular guilds.
- [x] **Cryptographic Manifest**: SHA-256 integrity verification across all indexed skills (`manifest.sha256`).
- [x] **Cross-Platform CI**: Automated verification across Ubuntu, macOS, and Windows with Python 3.11 and 3.12.
- [x] **Universal Protocol**: Instruction synchronization across Claude, Gemini, Cursor, and Windsurf.

---

## Phase 2: Packaging & Ecosystem Integration (v3.6)
- [ ] **Standalone Slop Court PyPI Package**: Publish `pip install slop-court` as an independent CLI and pre-commit hook repository.
- [ ] **Native `pre-commit` Hook**: Official `.pre-commit-hooks.yaml` definition for plug-and-play adoption in external repositories.
- [ ] **Extended AST Support**: Native tree-sitter AST parsers for TypeScript, Go, and Rust (moving from regex heuristics to full deterministic AST).
- [ ] **Skill Search Index Cache**: SQLite / DuckDB fast local index for sub-millisecond skill searches.

---

## Phase 3: Autonomous Swarms & Multi-Agent Dialectics (v4.0)
- [ ] **Distributed Supreme Council**: Asynchronous multi-agent deliberation via local Ollama / vLLM inference or cloud APIs.
- [ ] **Self-Reforming AST Code Repair**: Automatic syntax-level remediation for Misdemeanor violations during commit.
- [ ] **Interactive Web Inspector**: Local browser-based dashboard visualizing skill dependency graphs and Slop Court analytics.

---
