# Reference Collections

Curated awesome-lists, system-prompt archives, and directories of skills/MCP servers/plugins. Use these as hunting grounds when expanding the master [`skills/`](../../skills/SKILLS_INDEX.md) library or configuring new agent integrations.

| [`awesome-mcp-servers`](./awesome-mcp-servers) | [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) | Large directory of MCP servers organized by category (README snapshot). |

## Maintenance

- References are shallow copies (`--depth 1`, `.git` stripped) or README snapshots of large repos. Refresh periodically with `git pull`.
- When you find something useful, merge the skill into `skills/` and regenerate the indexes.
