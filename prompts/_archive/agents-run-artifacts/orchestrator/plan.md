# Orchestration Plan: Website Reconnaissance AI System Prompt & Operational Spec

## Overview
Decompose the project into 3 distinct milestones:
1. **Milestone 1: Research & Structural Blueprinting**
   - Explore requirements R1-R4.
   - Design the 6-phase operational workflow and architectural principles for website analysis, AST parsing, network mapping, API reconstruction, and blueprint output formatting.
2. **Milestone 2: System Prompt, Operational Spec & Output Schema Implementation**
   - Generate `SYSTEM_PROMPT.md` (6-phase agent workflow).
   - Generate `OPERATIONAL_SPEC.md` (detailed mechanics, AST/network parsing, edge-case mitigations).
   - Generate `OUTPUT_SCHEMAS.md` (JSON Schema and Markdown artifacts for Endpoint Catalogs, Component Trees, State Flows, Data Specs).
3. **Milestone 3: Verification Matrix & Quality Audit**
   - Generate `VERIFICATION_MATRIX.md` (evaluation rubrics and benchmark criteria across SPAs, SSR, and API architectures).
   - Run multi-agent review and verification.

## Execution Strategy
- Use subagents for all exploratory, authoring, and reviewing steps.
- Maintain persistent state in `BRIEFING.md` and `progress.md`.
- Ensure all artifacts are production-grade, comprehensive, and fully aligned with user requirements R1-R4.
