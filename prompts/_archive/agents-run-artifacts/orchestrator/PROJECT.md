# Project: Website Reconnaissance AI System Prompt & Operational Spec

## Architecture
This project produces a comprehensive, production-grade System Prompt, Operational Specification, Output Schema Suite, and Verification Matrix for AI coding agents tasked with technical website analysis, client-side logic parsing, network telemetry inference, API schema reconstruction, and technical blueprint synthesis.

The output artifacts will be saved in the root directory:
- `SYSTEM_PROMPT.md`: The complete, production-grade 6-phase system prompt for AI reconnaissance agents.
- `OPERATIONAL_SPEC.md`: Detailed operational mechanics covering DOM parsing, JS AST analysis, telemetry interception, and edge-case handling.
- `OUTPUT_SCHEMAS.md`: Markdown and JSON Schema specifications for Endpoint Catalogs, Component Graphs, State Machines, and Data Models.
- `VERIFICATION_MATRIX.md`: Comprehensive evaluation rubrics, test benchmarks, and quality validation matrices for SPAs, SSR, and protected APIs.
